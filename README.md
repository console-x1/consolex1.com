# consolex1

Site vitrine simple pour l’hébergeur consolex1, construit avec Next.js et prêt pour un déploiement statique sur GitHub Pages.

## Commandes

- `npm install`
- `npm run dev`
- `npm run build`

## Déploiement

Le workflow GitHub Actions `.github/workflows/nextjs.yml` construit et publie le site dans le dossier `out`.
